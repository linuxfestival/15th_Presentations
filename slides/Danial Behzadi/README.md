# چه‌کسی رایانش را وامی‌پاید؟ آزادی نرم‌افزار در عصر هوشواره و ابرواره

<p dir="ltr" align="left"><strong>Presenter:</strong> Danial Behzadi</p>

**Session:** Talk

## Abstract

Artificial intelligence and cloud computing are changing the very meaning of software. Increasingly, users are not given a program that they can run, study, modify, and share. Instead, they send their data to a remote service, use a model whose weights may not be available, and depend on infrastructure controlled by someone else.
This talk asks whether the traditional Four Freedoms are sufficient for this new environment. What does it mean to study an AI system? Is a model with open weights free software? Can ownership exist without local control? And does access through an API actually provide freedom?
