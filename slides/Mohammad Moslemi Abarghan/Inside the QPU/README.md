# Inside the QPU: Building Quantum Hardware Drivers on Linux

<p dir="ltr" align="left"><strong>Presenter:</strong> Mohammad Moslemi Abarghan</p>

**Session:** Workshop

## Abstract

This hands-on workshop explores how quantum hardware can be exposed as a Linux device, focusing on the systems layer between the CPU and a Quantum Processing Unit (QPU). Participants will work with PCIe, MMIO, DMA, interrupts, and Linux kernel-driver interfaces.

Using a virtual QPU implemented as a QEMU PCI device, participants will build and interact with a basic Linux driver and connect it to a quantum simulation backend. The workshop provides a practical introduction to applying familiar accelerator-driver concepts to quantum hardware.
