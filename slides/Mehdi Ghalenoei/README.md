# The Open Source Agent Stack

<p dir="ltr" align="left"><strong>Presenter:</strong> Mehdi Ghalenoei</p>

**Session:** Talk

## Abstract

Software is evolving from deterministic code to probabilistic AI agents, pushing current microservices and CI/CD pipelines past their limits. This session explores the emerging Open Source Agentic Stack by looking at how an existing enterprise system can grow a modern agent layer. We will tackle the core problems faced when architecting AI agents—including context management, the reliable evaluation of probabilistic workflows, and observability—and establish criteria for assessing new agentic concepts. By unpacking the Agent Development Lifecycle (ADLC) and open Linux Foundation protocols like MCP, A2A, and A2UI, you will discover how community-driven standards make modern agent systems modular, interoperable, and production-ready.
