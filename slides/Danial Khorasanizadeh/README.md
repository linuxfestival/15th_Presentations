# Who moved my libs? How to secure the software supply chain—from source to runtime

<p dir="ltr" align="left"><strong>Presenter:</strong> Danial Khorasanizadeh</p>

**Session:** Talk

## Abstract

Today, no application is built or runs in isolation. Software relies on a range of libraries, tools, dependencies, and runtime environments. This chain of dependencies has expanded software security beyond the code itself, making the assessment and monitoring of every component involved in building, releasing, and running an application an essential part of security.
In this talk, we will discuss the challenges of securing the software supply chain and the approaches used to identify, monitor, and manage them.
