# C++ Reimagined: Rediscovering the Language through C++11 to C++26

<p dir="ltr" align="left"><strong>Presenter:</strong> Ali Jafarabadi</p>

**Session:** Talk

## Abstract

C++ has evolved significantly since C++11. This talk explores how modern features such as smart pointers, concepts, ranges, coroutines, and modules enable clearer, safer, and more expressive software while preserving performance. It aims to challenge outdated perceptions and present C++ as a modern, evolving language.
