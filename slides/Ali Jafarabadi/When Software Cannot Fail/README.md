# When Software Cannot Fail: Navigating Trade-offs in Life-Critical Systems

<p dir="ltr" align="left"><strong>Presenter:</strong> Ali Jafarabadi</p>

**Session:** Talk

## Abstract

In life-critical systems, engineers must balance safety, reliability, performance, cost, and complexity. This talk introduces core concepts such as risk, fault tolerance, validation, and monitoring, while exploring how to make informed decisions when failure is unacceptable.
