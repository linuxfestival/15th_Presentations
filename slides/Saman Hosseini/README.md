# Kubernetes For Developers

<p dir="ltr" align="left"><strong>Presenter:</strong> Saman Hosseini</p>

**Session:** Workshop

## Abstract

We will explore the world of application containerization and how modern applications are deployed and managed at scale. The talk will focus on orchestration concepts, with Kubernetes as the main example, covering how it helps scale, maintain, and operate applications in real-world environments.
By the end, you will have a solid understanding of how Kubernetes works internally and how developers can use it for more effective application deployment.

Prerequisites: Docker & Linux.
