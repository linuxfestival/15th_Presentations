# A Tour of Linux Malware Techniques

<p dir="ltr" align="left"><strong>Presenter:</strong> Abolfazl Kazemi</p>

**Session:** Talk

## Abstract

A practical look under the hood of modern Linux threats. We’ll explore real-world offensive tradecraft—from stealthy execution to kernel-level persistence—and how to detect them.

What we’ll cover:

- Fileless & in-memory execution (memfd_create, injection)
- Evasion tactics (LD_PRELOAD, process hiding)
- Kernel rootkits & modern eBPF abuse
- Runtime detection and telemetry strategies
