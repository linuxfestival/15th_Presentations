# Automation Without Borders

<p dir="ltr" align="left"><strong>Presenter:</strong> Farshad Nickfetrat</p>

**Session:** Talk

## Abstract (summary)

This talk traces automation from the Industrial Revolution to AI agents. It uses the Knight Capital and GitLab incidents to explore how automation can prevent expensive mistakes and improve efficiency. Topics include Bash scripts, traditional server management, Infrastructure as Code with Ansible and Terraform, workflow automation with n8n, and AI agents.

The practical example provisions a virtual machine on cloud infrastructure, prepares a lab environment, manages its lifecycle, and removes resources after a defined period to reduce costs. The session also considers how AI agents can execute and manage processes within defined permissions and constraints. It is aimed at Linux enthusiasts, computer engineering students, developers, DevOps engineers, and anyone interested in automation.
