انقلاب Cursor

  • ادغام عوامل LLM داخل ادیتور
  • جریان کاری جدید: گفتگو ← کد ← بازبینی

اما… وابستگی به وندور · اشتراک ماهانه · نگرانی حریم خصوصی · کمتر بودن کنترل روی مدل و داده

  • جامعه به‌سمت جایگزین‌های متن‌باز می‌رود

چرا متن‌باز برای Vibe Coding؟

  • حریم خصوصی: با مدل محلی، کد و کانتکست روی ماشین شما می‌ماند
  • BYOK: هارنس متن‌باز + مدل دلخواه — حتی مدل اختصاصی مثل Claude
  • OpenRouter / API ابری: انعطاف بیشتر، ولی کانتکست به provider می‌رود
  • شفافیت: کنترل پرامپت، ابزارها و جریان اجرا

ابزار متن‌باز به‌تنهایی کافی نیست؛ داده روی دستگاه می‌ماند فقط اگر مدل هم محلی باشد — مثلاً Ollama

از کدنویسی در ادیتور تا اجرای واقعی روی ماشین — مدل می‌تواند محلی یا ابری باشد

Harness چیست؟

  • مدل = مغز: فکر می‌کند و جواب می‌دهد؛ دست، ابزار و حافظهٔ بلندمدت ندارد
  • Harness همان لایه‌ای است که دور مدل می‌سازیم تا کار واقعی بکند
  • شامل این‌هاست:
    • حافظه: نشست‌ها و کانتکست قبلی
    • ابزارها: ترمینال، ویرایش فایل، جستجوی وب
    • مهارت‌ها: دستورالعمل‌های قابل‌استفادهٔ مجدد
    • یکپارچگی: CLI و پیام‌رسان‌هایی مثل Telegram و Slack
    • اجرای امن: محیط ایزوله مثل Docker یا SSH
    • حلقهٔ ایجنت: فکر ← ابزار ← نتیجه ← تکرار
  • مدل‌ها عوض می‌شوند؛ هارنسی که مال خودتان باشد حافظه، مهارت و جریان کار را نگه می‌دارد
  • خلاصه: مدل = مغز · Harness = بدن و فضای کار

Hermes Agent و OpenClaw هر دو Harness متن‌باز هستند

معرفی Hermes Agent

Nous Research

  • harness پایدار و متن‌باز برای ایجنت‌های خودمختار
  • از یک نشست به نشست بعد، چیزهایی که یاد گرفته را به یاد می‌آورد
  • ساخت و نگه‌داری مهارت در طول زمان
  • کنترل کامل ابزارها و CLI

نه فقط یک چت — یک هارنس ایجنت که یاد می‌گیرد و ماندگار می‌ماند

Hermes فراتر از Vibe Coding

  • ایجنت همه‌منظوره — نه فقط copilot یا افزونهٔ IDE
  • کاربردها: زیرساخت · پژوهش خودکار · کارهای OS
  • یکپارچگی چندکاناله: بات‌های Telegram / Discord

Local First: اجرا روی ماشین یا VPS شما — بدون تلمتری اجباری به سازنده؛ مدل می‌تواند محلی یا ابری باشد

معرفی OpenClaw

OpenClaw Foundation

  • Gateway خودمیزبان — ایجنت روی ماشین یا سرور شما
  • یک ایجنت، چند کانال: Telegram، Discord، Slack و پیام‌رسان‌های دیگر
  • هر مدل: ابری یا محلی؛ بدون سرویس واسط اجباری
  • حافظه، ابزار، مهارت و کار زمان‌بندی‌شده

متن‌باز MIT — هارنس همه‌منظوره، نه فقط copilot داخل ادیتور
